# libmpv for Discord Auto-Compress

Download mirror for the editor's built-in player. `libmpv-2.dll.z.0..3` concatenated are a zlib stream of
`libmpv-2.dll` (mpv, build by shinchiro/mpv-winbuild-cmake, tag 20261111, x86_64).
mpv is free software (GPLv2+ / LGPL): source https://github.com/mpv-player/mpv ,
build scripts https://github.com/shinchiro/mpv-winbuild-cmake
